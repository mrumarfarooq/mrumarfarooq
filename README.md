## Featured Project

### ResumeATS — AI-Powered Resume Analyzer

**[GitHub Repository](https://github.com/mrumarfarooq/AI-Resume-ATS)**

An AI-assisted resume analysis application built with Python that evaluates resumes, analyzes job-role and job-description compatibility, and generates detailed feedback and downloadable reports.

**Tech Stack:** Python, FastAPI, Streamlit, Supabase, Groq API, spaCy, Sentence Transformers, RapidFuzz, WeasyPrint

**Key Features**
- Developed REST APIs for resume analysis, user history, and PDF report generation.
- Implemented a custom ATS scoring system evaluating formatting, keywords, content, skill validation, and compatibility.
- Built job-role and job-description matching with evidence-based skill evaluation.
- Integrated NLP, semantic similarity, and AI-assisted structured parsing for resume and job-description analysis.
- Implemented user authentication and analysis history using Supabase.
- Generated downloadable PDF reports with scores, strengths, issues, and improvement recommendations.

**Note:** ATS scores are application-generated assessments and do not represent scores from a specific employer's applicant tracking system.
